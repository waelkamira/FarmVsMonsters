# Farm Vs Monsters

مشروع لعبة مستقلة مبني على Unity 3D وC# وURP، بأسلوب Stylized 3D وكاميرا Isometric. تجمع اللعبة بين معارك دفاع استراتيجية ومزرعة دائمة قابلة للبناء والتطوير.

> الحالة عند إنشاء المستودع: وثائق وهيكل تأسيسي فقط. لم يُنشأ بعد مشروع Unity فعلي أو مشاهد لعب أو نماذج ثلاثية الأبعاد.

## المنصات
- Windows: التطوير والاختبار الأساسي.
- Android: اختبار مستمر.
- iOS: هدف الإصدار الأول.

## النموذج الأولي
مزارع واحد، 5 نباتات، حيوانان، 5 وحوش، زعيم واحد، ساحة واحدة، 3 مراحل، 5 موجات لكل مرحلة، مبنيان و3 أدوات.

## أولوية التنفيذ
بناء حلقة لعب فعلية: اختيار مرحلة، الحركة، جمع الطاقة، زراعة الوحدات، القتال والموجات، الفوز/الخسارة، المكافآت، العودة للمزرعة، التطوير والحفظ.

راجع `Documentation/BUILD_LOG.md` لتتبع ما نُفذ فعلياً.
