# Farm Vs Monsters

لعبة دفاع ومزرعة **ثنائية الأبعاد فقط (2D)** بأسلوب كرتوني مرسوم يدوياً وشخصيات أصلية.

## الاتجاه التقني الحالي
- **إعادة البناء الجديدة:** Next.js + React + JavaScript + Phaser 3 داخل المجلد `web/`.
- **النسخة القديمة:** مشروع Unity الموجود في جذر المستودع محفوظ كمرجع أثناء نقل الأنظمة؛ لا نحذفه قبل إعادة بناء الأنظمة والتحقق منها في النسخة الجديدة.
- Windows PC هو هدف النموذج الأول، ثم الهواتف والتغليف المكتبي.

## قواعد اللعب المعتمدة
- النباتات ثابتة في خلاياها؛ تتنفس بهدوء وتهاجم من موضعها وفق طبيعتها، ولا تمشي أبداً.
- الوحوش هي التي تتقدم عبر المسارات. حركتها الأولى بطيئة وثقيلة ومتعرجة، وتزداد سرعتها تدريجياً مع المراحل.
- رجل الكهف يزرع النباتات ويرعى المزرعة. لا يهاجم الوحوش ما دامت هناك نبتة مدافعة حية.
- عند موت آخر نبتة مدافعة يبدأ وضع الطوارئ، ويقاتل رجل الكهف بالعصا فقط.
- إذا زُرعت نبتة جديدة بنجاح، يعود الدفاع النباتي ويتوقف قتال رجل الكهف.
- المنزل والأميرة في نهاية المزرعة المحمية، والوحوش تدخل من الطرف المقابل.

التفاصيل الملزمة في `Documentation/NEW_GAMEPLAY_RULES_2D.md`.

## تشغيل نموذج الويب

```bash
cd web
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

النموذج الحالي يستخدم أشكال Phaser مؤقتة للتحقق من منطق اللعب. سيتم استبدالها برسومات الشخصيات الأصلية وSprite Sheets التي يرفعها المستخدم. لم يتم بعد تشغيل npm install أو تنفيذ build في بيئة التطوير.

## ملاحظة حول Unity
توجد أنظمة Unity/C# سابقة في المستودع. تبقى مرجعاً للمفاهيم والبيانات أثناء إعادة البناء، لكنها ليست محرك النسخة الجديدة. لا تعتبر النسخة الجديدة مكافئة للأنظمة القديمة قبل نقل كل نظام واختباره.
