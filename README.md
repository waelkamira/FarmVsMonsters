# Farm Vs Monsters

لعبة استراتيجية ومزرعة دفاعية. **الاتجاه الفني المعتمد حالياً هو 2D Hand-Drawn Cartoon** مستوحى من اللغة البصرية العامة لألعاب الدفاع الكرتونية الكلاسيكية مثل Plants vs. Zombies، مع شخصيات أصلية خاصة بالمشروع. لم يعد أسلوب Stylized 3D / Low Poly هو الهدف الفني.

## الرؤية الفنية واللعب
- نباتات وزومبي ووحوش مرسومة يدوياً بتعابير مبالغ فيها وظلال ناعمة وحدود واضحة.
- معارك جانبية 2D قائمة على مسارات وصفوف وخلايا زراعة.
- Sprite animations للحركة والهجوم والإصابة والموت.
- مزرعة دائمة لإنتاج المحاصيل وتربية الحيوانات والتصنيع والتخزين والبيع والترقية.
- يجب أن تكون كل الشخصيات والبيئات والمؤثرات أصلية؛ لا ننسخ رسومات أو شخصيات أو واجهات محمية من ألعاب أخرى.

راجع `Documentation/ART_DIRECTION_2D.md` قبل إنشاء أي أصل فني.

## حالة التطوير
- إصدار المحرر المستهدف: **Unity 6.3 LTS — 6000.3.27f2** (راجع `ProjectSettings/ProjectVersion.txt`).
- أنظمة الاقتصاد والتقدم والمحاصيل والحيوانات والإنتاج والتخزين والسوق موجودة في الشيفرة كنواة أولية.
- أضيفت نواة قتال 2D: شبكة خلايا، وضع النباتات، إدخال سطح المكتب، حركة الأعداء أفقياً، هجمات النباتات والمقذوفات، وتحريك Sprite بالإطارات.
- تمت تهيئة مدير الموجات الحالي لقبول أعداء 2D إلى جانب النماذج القديمة.
- مولدات المشاهد الحالية ما زالت تنتج مشاهد 3D رمادية قديمة؛ لم يتم بعد استبدالها بمولد مشهد 2D متكامل أو ربط جميع أنظمة 2D في مشهد واحد.
- **لم يتم تشغيل Unity أو إجراء Compile أو Play Mode أو Build في هذه الجلسة**. لا تعتبر النسخة قابلة للعب قبل فتحها في Unity وإتمام التحقق.

## المنصات
1. Windows PC — أول منصة للنموذج القابل للعب.
2. Android — بعد تثبيت حلقة اللعب.
3. iOS — بعد استقرار التحكم والأداء.

## الخطوة التالية داخل Unity
1. ثبّت Unity Editor بالإصدار الموجود في `ProjectSettings/ProjectVersion.txt`.
2. افتح المشروع وانتظر استيراد الملفات.
3. لا تعتمد مولدات 3D القديمة كالمشهد الفني النهائي؛ إنها نماذج هندسية مؤقتة.
4. الخطوة التطويرية التالية هي إنشاء مولّد مشهد معركة 2D يربط `BattleGrid2D` و`PlantPlacementService2D` و`DesktopBattleInput2D` ومكونات العدو والنبات والـ HUD، ثم إنشاء مشهد مزرعة 2D.
5. راجع Console وأصلح أخطاء التجميع قبل اختبار الحلقة الكاملة.

## حلقة اللعب المستهدفة
إدارة المزرعة ← زراعة وإنتاج وجمع الموارد ← تصنيع وبيع وتطوير ← تجهيز النباتات والطاقة ← صد موجات الوحوش ← مكافآت وفتح مراحل ← العودة لتطوير المزرعة.
