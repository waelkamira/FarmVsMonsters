## Selection rules before importing

1. Prefer one coherent 2D cartoon art style: rounded forms, clear silhouettes, saturated plant/monster colors and consistent outline weight.
2. A single character image is not an animation sheet. Verify each action independently and count its real frames; the target remains 24 genuine frames per required state.
3. Keep UI artwork separate from character sprites. Buttons, panels, icons and HUD pieces should be exported as individual assets where possible.
4. Store the original source URL, creator, licence/permission, dimensions, frame layout and import date beside every imported asset.
5. Temporary copyrighted references may be used locally for development review only where appropriate; they are not cleared for redistribution or commercial release. Replace or license them before release.
