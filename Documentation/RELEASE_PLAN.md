# Release Plan

1. Foundation: Unity project, URP, Input System, folders, conventions.
2. Vertical slice: farmer movement, one arena, placement, one plant, one enemy, one wave.
3. Combat prototype: full initial roster, five waves, boss, win/loss and rewards.
4. Farm progression: buildings, upgrades, inventory, save/load.
5. Content and polish: three stages, art/audio, UX, performance.
6. Platform validation: Windows, Android, iOS readiness.

Do not start monetization or multiplayer before the single-player loop is stable.
