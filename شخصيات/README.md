# شخصيات اللعبة

هذا المجلد مخصص لرسومات شخصيات **Farm Vs Monsters** الأصلية.

## التصنيفات
- `النباتات/`: النباتات المدافعة والشخصيات النباتية.
- `الوحوش/`: الوحوش العادية والمتخصصة.
- `الزعماء/`: زعماء المراحل والوحوش الضخمة.
- `الحيوانات/`: حيوانات المزرعة وأي حيوانات تدخل أسلوب اللعب.
- `الشخصيات_المساعدة/`: المزارع والشخصيات غير القتالية.

## طريقة رفع الرسومات
ارفع كل صورة داخل مجلد التصنيف المناسب. يفضّل أن يكون اسم الملف واضحاً وبالإنجليزية أو العربية، مثل:
- `Sunflower_Idle.png`
- `Basic_Monster_Walk.png`
- `Farm_Boss_Attack.png`

يمكن رفع صورة مرجعية أولية حتى لو لم تكن Sprite Sheet نهائية. لا حاجة إلى قصّ الصور أو تجهيزها للعبة قبل مراجعتها.

## ملاحظات فنية
- الاتجاه المعتمد: رسوم ثنائية الأبعاد مرسومة يدوياً، بروح كرتونية كوميدية وألوان حيوية.
- نريد تصاميم أصلية خاصة باللعبة، لا نسخاً مباشرة لشخصيات أو رسومات ألعاب أخرى.
- عند توفر الحالات الحركية، ارفعها منفصلة أو كـ Sprite Sheet، واكتب اسم الحالة في اسم الملف: Idle, Walk, Attack, Hurt, Death.
- لا تستبدل الرسومات المرجعية أو تحذفها قبل مراجعتها.
